Sistema de Agendamento Inteligente com IA e n8n

Este projeto é uma automação avançada de agendamento desenvolvida no n8n, que utiliza Inteligência Artificial para gerenciar o calendário de forma totalmente autônoma. O sistema atua como um assistente virtual no WhatsApp, interpretando mensagens, verificando disponibilidade e gerenciando compromissos sem necessidade de intervenção humana.

n8n WhatsApp API AI Agent Google Calendar Google Meet Google Sheets Webhooks

Principais Funcionalidades:

  • Interação Natural: A IA identifica a intenção do cliente (agendar, reagendar ou cancelar) e coleta os dados necessários (data, horário e motivo) de forma conversacional.
  • Gestão Autônoma de Calendário: O sistema acessa o Google Calendar em tempo real para criar, mover ou excluir eventos automaticamente.
  • Validação Inteligente: Antes de confirmar, a automação verifica conflitos de horário, valida formatos de data e previne duplicidade de agendamentos.
  • Integração com Google Meet: Para reuniões online, o fluxo cria automaticamente o link da videochamada e envia os dados de acesso diretamente para o cliente no WhatsApp.
  • Organização de Dados: Todos os registros e históricos são salvos automaticamente em uma Google Sheets para controle administrativo.
